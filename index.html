❔ Guide PilotPerf

🔄 Actualiser

Relit le dossier OneDrive configuré : seuls les fichiers nouveaux ou modifiés sont lus. L'actualisation automatique se règle dans Sources & OneDrive.

⌕ Recherche

Nom, code (485, IS51798), n° de dossier, atelier, marque, magasin ou pièce. Combinez : 485 semaine 46, AIR TAN, dyson +30j. Touche /.

🎛 Filtres

Site, atelier et période s'appliquent à tous les écrans. Les encours sont une photographie à date : la période ne s'y applique pas.

★ Vues enregistrées

Mémorisez un écran avec ses filtres (ex. « Robots du mois ») et retrouvez-le en un clic.

🧭 Pilotage

Les dossiers à traiter : retards sur date promise, échéances, futurs +30 j, bloqués, pièces, devis sans réponse, sans action.

🖨 Imprimer / ⬇ Image / Excel

Survolez un graphique ou un tableau : imprimer, enregistrer en image ou exporter vers Excel. Filigrane « Confidentiel » et logo Fnac Darty ajoutés.

📄 Rapport

Sur le tableau de bord : une synthèse de la période prête à enregistrer en PDF.

📺 Écran atelier

Plein écran, les tableaux défilent seuls. → pour passer, Échap pour quitter.

⌨️ Raccourcis

/ recherche · Alt + ← retour · Échap fermer · ↑ ↓ Entrée dans les menus.

🔒 Administration

Ajouter des fichiers, choisir les dossiers, ouvrir une sauvegarde et modifier les réglages demandent le code superviseur.

🔒 Accès superviseur

Saisissez le code superviseur pour gérer les sources de données.
